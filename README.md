# Sales-Data-Analysis-Python
Sales data analysis and visualization using Python, Pandas, NumPy, Matplotlib, and Seaborn.
## Project Overview

This project analyzes sales transaction data using Python to identify sales trends, product performance, regional performance, profitability, and salesperson performance.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Data Cleaning

- Analyzed and handled missing values
- Identified and removed duplicate records
- Prepared data for analysis

## Analysis Performed

- Regional Sales Analysis
- Product-Wise Sales Analysis
- Salesperson Performance Analysis
- Regional Profit Margin Analysis
- Product Profitability Analysis
- Product-Wise Quantity Analysis
- Top 5 Highest-Value Orders
- Monthly Sales Trend Analysis
- Average and Median Sales Analysis
- Sales Range and Variability Analysis
- Discount vs Total Sales Analysis

## Visualizations

Created visualizations using Matplotlib and Seaborn to analyze:

- Regional sales comparison
- Monthly sales trends
- Discount vs. total sales relationship

## Project Files

- `Sales_Data_Analysis.ipynb` – Python analysis and visualizations
- `Data.xlsx` – Dataset used for analysis
